A miss we found, and published.

What happened

A desktop application sent its system prompt first. User messages carrying real identifiers and a cloud credential were forwarded as allow, while the same values in a single-message request were correctly stopped. Content extraction had stopped at the first message.

Why you are reading about it

We found it by governing a real application, not a test set. It was fixed the same day, the corpus gained the case, and a probe now challenges it daily.
