# Figma Make prompt — GovernVeil marketing site

Design a 5-page marketing website for **GovernVeil**, a self-hosted AI data-egress control and evidence platform for regulated enterprises (BFSI, healthcare, GCCs). Positioning: "AI guardrail governance — the court of record for every AI decision." The brand voice is **evidence-first**: every claim carries a number, a mechanism, or a named model; anything not shipped is tagged `roadmap` in orange. Never invent numbers or customer logos.

## Design system (Ant Design language)

- Colors: primary #1677ff; ink text #141414/#26333f; secondary text #595959; borders #f0f0f0; tinted band #f6f9fe/#fafafa; dark band #141414 with #303030 borders; success #52c41a; warning #faad14; danger #ff4d4f; purple #722ed1.
- Verdict tag component (used everywhere): small rounded chip with 6px dot + label — allow (green #f6ffed/#b7eb8f/#389e0d), review (purple #f9f0ff/#d3adf7/#531dab), redact + mask (blue #e6f4ff/#91caff/#0958d9), block (red #fff2f0/#ffccc7/#cf1322).
- Type: system sans (SF/Segoe/Roboto); hero 52px semibold, tight -1.4px; section titles 26–30px; body 14–15px/1.65; code + metrics in ui-monospace.
- Layout: 1160px max width, generous whitespace, left-aligned section heads with an uppercase 12px letterspaced eyebrow label above each title. Sections alternate white / tinted / dark. Cards: 1px #f0f0f0 border, 10px radius, equal heights per row, hover border darkens.
- Header: sticky white, logo "GovernVeil" (blue shield mark), nav Product / Features / About, primary button "Book a pilot". Footer: dark, brand + tagline ("AI guardrail governance — the court of record for every AI decision. A Syntegreti platform. Hyderabad, India."), columns Product / Evaluate / Company, line "Self-hosted. Your data never leaves your perimeter."

## Rules

- Use only the numbers and examples given above — do not invent metrics, logos, testimonials, or customer names.
- Every roadmap item gets a visible orange `roadmap` tag; shipped and roadmap must be visually distinct.
- Mono font for anything technical: metrics, paths, payloads, code chips, terminal cards.
- Desktop 1440px primary; show mobile (390px) for Home hero + enforcement log (columns collapse: hide payload column, stack).
