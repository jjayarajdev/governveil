Masking that gives the answer back

On your apps' API calls it is a full round trip: realistic, format-preserving surrogates go out, and the real values are restored in the answer. The provider works on stand-ins; your app never notices.

Why it matters: detect-and-block tools stop the work, so users route around them. Masking keeps the work moving while the data stays home.

The browser is covered too

A managed extension governs ChatGPT and claude.ai in the page itself: mask outbound, block, or a review notice, before the message ever leaves the tab. People keep working with the stand-ins on screen; restoring another company's web UI isn't reliably achievable, so we don't claim it.

And it remembers the conversation. A profile leaked one harmless field at a time across five turns still trips detection. Single-prompt filters never see that.

Files get searched before models read them

Uploads are parsed and swept for the channels attackers actually use: white-on-white text, hidden sheets and comments, macro and script payloads. Hostile files are quarantined before any LLM or RAG pipeline sees them.

The risk it closes: a prompt-uploaded file can carry instructions no human reviewer ever sees, and perimeter DLP doesn't look inside it. The sweep closes that door before a model opens the file.

An off-switch for vendor AI

Every third-party AI credential lives in a registry: which vendor, which agent, what scope. When something looks wrong, revoke the grant and every request on that credential is refused inline, in under a millisecond.

The failure it prevents: the classic breach is the forgotten grant that outlives the contract. An inventory can list it; only an inline control can shut it off.

Detection that learns on your data, in your walls

Borderline prompts go to a human review queue. Confirmed labels retrain the classifier, and only a model that passes the evaluation gate is promoted. It happened for real: a rewording evasion went from caught 85% of the time to 100%.

Why self-hosting matters here: detection can only learn from your data if your data never has to leave. Residency is not just a compliance checkbox; it is the compounding edge.
